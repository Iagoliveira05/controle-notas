# Arquitetura
React 19 + TypeScript + Vite, sem dependências externas obrigatórias. `App.tsx` contém a primeira casca funcional; `App.css` e `index.css` definem a interface responsiva. O estado atual persiste gastos no `localStorage`. A evolução prevista separa domínio, persistência Firebase, OCR local Tesseract.js e componentes.
